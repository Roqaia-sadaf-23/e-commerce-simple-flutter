# 🛍️ Simple E-Commerce Flutter App

A mobile e-commerce application built with **Flutter and Dart**.

The application provides a simple shopping experience where users can browse products, view categories, manage their shopping cart, save favorite products, and manage delivery addresses.

This Flutter application is designed to work with an **ASP.NET Core Web API backend**.

---

## 📱 About the Project

This project was created to practice building a complete mobile application with Flutter and connecting it to a backend REST API.

The application focuses on implementing common e-commerce functionality while keeping the code organized and separating the application logic from the user interface.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Roqaia-sadaf-23/e-commerce-simple-flutter.git
```

### 2. Open the project

```bash
cd e-commerce-simple-flutter
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Check Flutter setup

```bash
flutter doctor
```

### 5. Run the application

```bash
flutter run
```

---

## 🔗 Connecting to the Backend

Make sure the ASP.NET Core backend is running before using features that require API data.

When testing with an Android emulator, your backend URL may need to use:

```text
10.0.2.2
```

instead of:

```text
localhost
```

When testing on a physical device, use the local IP address of the computer running the backend.
